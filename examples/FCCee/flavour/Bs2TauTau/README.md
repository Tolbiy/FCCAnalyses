## Example search for Bs to tau tau decay

### Overview

Analysis set to study sensitivity for Bs to tau tau decay.
Initial commit based on BuBc2TauNu analysis, focusing on tau to 3pi decays.

### Scripts
`analysis_stage1.py` does hemisphere splitting, displaced vertex reconstruction, and tau to 3pi decay reconstruction.
`mumu/analysis_stage1.py` does hemisphere splitting, displaced vertex reconstruction, and recovers muons info as well as truth-matching for tau to mu analysis.
